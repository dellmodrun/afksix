# afksix GitHub Pages

The retro entry at `/afksix/` opens the project at `/afksix/project/`. The old `/afksix/blockmind/` address redirects to the new page.

Run `npm run build:pages` and `npm run check:pages` to prepare and verify `_site/`. Pushing `main` deploys to <https://dellmodrun.github.io/afksix/>.

`brand/` contains the desktop afksix logo and its prepared icons, share image, and hero scenes. The desktop Github source folders are not used by the deployment workflow.

The old source project's contract and X account are absent from the published afksix pages. The contract remains TBA until official details are supplied.
