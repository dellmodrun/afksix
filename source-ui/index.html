README / afksix exploration core

An autonomous exploration baseline you can run today. It observes a small simulated city, chooses where to go, plans a road route, moves, checks the result, and keeps a short memory. Every step produces an inspectable event. The same core powers the interactive demo on this page.

Quick start

node src/cli.mjs demo 60 6
node --test test/*.test.mjs

Requires Node.js 20 or newer. There are no runtime dependencies or API keys. The CLI writes JSON events to standard output and a summary to standard error. Set AFKSIX_OUTPUT=run.json to save the full run.

What it actually does

  • Chooses destinations and plans routes through a road grid.
  • Performs an observe → choose → act → check → remember cycle.
  • Records a trace with positions, decisions, actions and outcomes.
  • Runs deterministically so another person can repeat the same result.

Integration status

The simulation core runs. GTA VI screen capture, game input, model inference and live streaming are not connected. A verified public game run is still required before those features can be claimed.
